`spec/09-registry.md` of 0.10.0 defines an abstract registry contract only; it
does not name a concrete on-chain implementation. This folder therefore holds
no sources, no build and no tests. Existing 0.10.0 integrations keep their
separate qualification. The first concrete chain Registry is the 0.11.0 one in
[`../v4`](../v4/README.md).

[docs/DEPLOYMENTS.md](docs/DEPLOYMENTS.md) records that nothing was deployed for
this version.
